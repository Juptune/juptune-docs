## Default Certificate Store

<Aside type="danger">
    Any certificate in the bundle that fails to parse is silently discarded, this can lead to confusing errors about missing root certificates.

    Feel free to raise an issue with any specific certificate PEMs that are failing so I can eventually look into the decoding error (they're such a PITA though)!
</Aside>

Juptune will attempt to load the default CA bundle from one of these file paths, using the first file that exists:

* /etc/ssl/ca-bundle.pem
* /etc/ssl/certs/ca-certificates.crt
